# センゴク盤 ロゴ

## 入っているもの

| ファイル | 大きさ | 用途 |
|---|---|---|
| `sengokuban-seal.svg` | 512×512 | 印章（字あり）。起動画面、題名まわり |
| `sengokuban-mark.svg` | 512×512 | 印章（字なし）。小さく使うとき（48px 以下） |
| `sengokuban-title.svg` | 1200×360 | 題字。地は透明 |
| `sengokuban-title-onpaper.svg` | 1200×360 | 同上、紙色の地つき |

字はすべて輪郭に変換してある（欧文の副題 SENGOKU BAN のみ、Helvetica 系の
指定で置いた。欧文は相手の端末に必ずあるためである）。

## 決まりごと

### 色

| | 値 |
|---|---|
| 墨（地） | `#1C1E22` |
| 紙（駒・字の抜き） | `#F4F1E8` |
| 枡目の線 | 白・不透明度 0.353・太さ 5.5（512 基準） |
| 藍（味方） | `#2F5D8C` |
| 朱（敵） | `#B0483C` |

### 形の由来

騎馬の駒（後ろが二股に割れた形）を左右へ七割広げ、上向きに立てたもの。
穂先が上辺に、二股の尾が下辺に接する。中心に「盤」。

512 の設計空間での駒の輪郭は次のとおりである。

```
M 256 0  L 438.78 281.6  L 343.04 409.6  L 403.97 512
         L 256 435.2
         L 108.03 512  L 168.96 409.6  L 73.22 281.6  Z
```

### 使い分け

- **120px 以上**——字ありの `seal` を使う
- **120px 未満**——字なしの `mark` を使う。字が潰れるため
- **横に置くとき**—— `title` を使う

### してはいけないこと

- 縦横の比を変えない（印章は必ず正方形）
- 駒の形を変えない
- 色を変えない（藍地・朱地の版が要る場合は別途作る）

## 出どころ

作者から渡された PDF（`sengokubanmark` `sengokubanseal` `sengokubantitle`
`sengokubantitleonpaper`）のベクタを、そのまま SVG に写したものである。
座標は原本と同じで、目で見て一致することを確かめてある。以後はこの SVG が
出どころであって、PDF に戻る必要はない。
