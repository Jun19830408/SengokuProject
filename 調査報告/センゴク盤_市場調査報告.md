## 要旨(先に結論)

**遊びの中身は、個人開発としては例外的に深く、題材との噛み合いも良い。一方、商業的な見立ては「現状のままなら数百本、磨いて露出に成功すれば数千〜1万本台」が現実的な幅**(推測。根拠は後述の類似事例)。

- 実機で確認できた強み: 137家から選べる史実準拠の日本全図、兵站まで踏み込んだ出陣、天候・地形・陣形が効く合戦、勲功による武将取り立て(偏諱で名を選ぶ)、捕虜処遇、筋書きつき関ヶ原。歴史の「理屈」が通っており、信長の野望系の客層に刺さる質
- 実機で確認できた弱み: 大規模戦の動作の重さ(関ヶ原で顕著)、初見者への導入の薄さ(チュートリアルなし・情報量が多い)、見た目の地味さ、スマホ縦画面での画面の窮屈さ
- 売り方の本命は **Steam買い切り(1,000〜2,000円帯)+ブラウザ無料体験版を宣伝装置にする**構成。スマホアプリ化は優先度低
- ただし個人開発SLGのSteam売上中央値は数百ドルという厳しい統計があり、**露出(Steam Nextフェス、配信者向けデモ)が成否をほぼ決める**

## 一、実機プレイ評価

### 1. 初めて遊ぶ人の最初の30分(実プレイの記録)

織田家で新規開始し、「題名 → 大名選び → 地図 → 内政 → 出陣 → 野戦勝利 → 城攻め」まで実際に通しました。

**題名画面**(写真01)
起動から操作可能まで約5秒(3.8MBの一枚HTML)。釦は「ゲームをはじめる」「合戦──関ヶ原」「遊び方を読む」+記録所(自動1・手動5・救出1)。迷う要素がなく良好。※保存データがあると先頭が「続きから(自動・1546年8月・織田家)」に変わることも確認(写真50は本編の題名)。

**大名選び**(写真02・03)
日本全図+137家の一覧。大身/中堅/小勢力と地方での絞り込み、難易度(易/普通/難)。家を押すと「尾張下四郡の一族。父信秀のもと那古野に拠るが…」という史実解説と石高・兵数・当主が出る。**「この勢力を任せて見物する」(観戦モード)があるのは観察型プレイヤーに嬉しい作り**。初見でも織田・武田など有名家を選べば迷わない。

**地図と城**(写真04・05)
地形起伏・街道・郡境・家紋つきの城が描かれた本格的な全国図。画面下に「城も軍もタップすると詳細が開きます」という操作ヒントが常時出る。自城を開くと、城主・姫・石高・人口・兵糧(日数換算つき)・城防・民忠、直属/地域家臣団の内訳、武将10名の能力まで一画面に収まる。**情報量は豊富だが、初見者には多すぎて圧倒される恐れがある**(後述)。

**内政**(写真05)
開墾を実行すると石高18.8万→19.2万石、金銭−196貫、担当武将が消費される。効果が即座に数字で見え、「田を開けば、家の月の金銭は+862→+874貫」という事前表示も親切。

**月送りと月初報告**(写真08)
「次月へ」1回あたり約2.6〜2.9秒(この検証環境)。月初報告で「武田家が高遠城より出陣。深志城を目指す」など他家の動きが毎月届き、**世界が勝手に動いている感覚**がある。これはこのゲームの美点。

**出陣(陣触れ)**(写真11・14)
目標は経路と所要月数つきの一覧から選択。従属勢力(水野家)を選ぶと「ここへ兵を出せば攻撃となり、従属は破れて敵対します」と赤字で警告が出る(事故防止として優秀)。兵糧の積み月数・運び賃・他城からの加勢(応じる見込み90%等)・総大将の身分で届く範囲が決まる仕組みまで、**兵站が遊びになっている**。4,505人で清洲城(織田大和守家)へ進発。

**野戦(清洲城下・雨)**(写真18・20・24)
着陣すると軍議(攻めかかる/遅参を待つ/兵を退く)。開戦時に「自ら采を執る/諸将に委ねる/委ねたときの見込みを立てる」の三択があり、**忙しい人は委任で結果だけ見られる**。戦場は宿場の町+川+橋で、雨のため「火縄が湿り、鉄砲がほぼ使えない」。敵は索敵の霧の中で「敵影」として見え、下知(前進・接戦・突撃・射撃…)、7種の陣形(効能の説明つき)、計略(鼓舞)、分遣(騎馬側面攻撃・高地占拠・渡河点防衛…)が使える。敵AIも騎馬の側面攻撃分遣を出してきた。勝利時は損害の内訳(直属1,523人/地域773人)まで表示。

**城攻め**(写真34・36)
野戦勝利後は包囲の軍議: 兵糧攻め/付城(包囲率が上がり後詰を遮断)/強攻/撤退。攻城道具(破城槌・竹束・井楼)を武将ごとに持たせられる。強攻では惣構→二の丸→本丸の多重曲輪と門耐久(%表示)、城の傾き、水の手・焼き働き・内応の計略まである。**実戦では約3倍の兵力差でも強攻は跳ね返され、兵の半分を失って兵糧攻めに移行**。歴史的に正しい手応えだが、初見者が最初の城攻めで壊滅する可能性が高い(後述)。

**勲功と戦後処理**(写真38)
戦後、「中野藤七が戦功を挙げた。橋際で崩れかけた隊列を立て直し、敵の渡河を阻んだ」として正式武将への取り立てが発生。**主君から偏諱「盛」を受けて「盛光/光盛/盛元/元盛」から諱を選ぶ**演出は、このゲームにしかない看板体験と言ってよい。捕虜(坂井大膳)の処遇(登用/逃す/斬首/捕虜)も発生し、忠誠81のため「降ることを拒んだ」と、画面に明示された規則(忠誠71以上は決して降らぬ)どおりに動いた。

**最初の30分の総括**: 題名→初合戦まで実時間30〜40分で到達でき、その間に「世界が動く」「兵站が重い」「歴史の理屈で勝敗が決まる」という核が全部味わえる。**ただし誘導はヒント文のみで、チュートリアルはない**。信長の野望経験者なら迷わないが、未経験者には「最初に何をすべきか」の道標が足りない。

### 2. 操作の分かりやすさと手引き

- 画面内の説明文は非常に丁寧(各項目に効能・計算式・歴史的根拠が添えられる)。文体も「下知」「惣無事令」など統一され、雰囲気づくりに貢献
- 「遊び方」(写真41)は12章+画面例つきの本格的な説明書で、城名が年代で改まる(稲葉山→岐阜など)ことまで書かれている。**ただしこれは「読む手引き」であり、遊びながら教える仕組み(チュートリアル)ではない**
- モーダル(月初報告など)がEscキーで閉じない、報告を閉じる釦が「評定を開く」という名称で「閉じる」に見えない、戦場から戻ると同じ月初報告が再表示される、など小さな引っかかりがあった

### 3. スマートフォン縦画面(390×844)

- 題名・大名選び・城詳細(下からのシート表示)・月初報告は**縦画面できちんと再構成され、読みやすい**(写真m01・m05・m06)
- 問題点: (1)上部の資源帯が画面幅に収まらず石高・金銭が切れる、(2)左右の釦列が地図の約4割を覆う(写真m04)、(3)「第二試作版」の帯が「次月へ」釦に重なる(製品版では帯は消える想定)、(4)合戦画面は密集地で武将名ラベルが重なり読みにくい(写真m10)
- 関ヶ原の合戦もスマホ縦画面で起動・進行した(下に一括命令パネルが並ぶ配置)。**動くことは動くが、快適とは言えない**

### 4. 動作の重さと不具合

計測値(すべてこの検証環境=GPUなしのコンテナ内Chromium。実機のPC/スマホではこれより軽い可能性が高いことに注意):

| 項目 | 計測値 |
|---|---|
| 起動→題名操作可能 | 約5秒 |
| 月送り1回 | 約2.6〜2.9秒 |
| 野戦(約9,000人規模)のFPS | 約22 |
| 関ヶ原(17万5千人・63隊)のFPS | **約6**(1280×720) / 約18(スマホ縦の小画面) |
| 関ヶ原を委任で決着まで | 実時間10分超 |

- **関ヶ原の重さは商品化前の最大の技術課題**。委任中も実時間でシミュレーションが回るため、「結果だけ見たい」人にも10分以上かかる。倍速上限の引き上げか、委任時の非描画計算(引き継ぎ資料にある「画面を描かずに月次処理だけ回せば十倍速い」と同じ発想)が欲しい
- 不具合: 加勢を求める画面に**「GDD 7.3」という内部仕様書の節番号がそのまま表示**されている(陣触れ画面)。製品では削除すべき
- 音(曲・効果音)は、file://で開く検証環境ではブラウザの制約(fetchがfile:を読めない)で鳴らず、**確認できなかった**。HTTP配信(Netlify等)では読み込まれる作りに見えるが、未検証であることを明記する。コンソールにはこのfetch失敗のエラーが多数出るが、遊びには影響しなかった
- 進行不能・クラッシュ・表示崩れの類いは、今回の約2時間のプレイでは**一度も遭遇しなかった**。自動保存からの「続きから」も正常

### 5. 面白さの核と物足りない所

**核(実際に遊んで感じた順)**
1. 歴史の理屈がそのまま遊びの規則になっている(兵站・身分・偏諱・惣無事令・城名の改称)。この一貫性は大手作品にもあまりない
2. 月初報告で他家が動き続ける「生きた日本」感
3. 合戦の決断の質(天候で鉄砲が死ぬ、強攻の損害、去就未定の黄色い隊)。関ヶ原で「松尾山の小早川への備えを固めるか」という史実の決断(筋書き6件)を迫られるのは秀逸
4. 委任と手動を行き来できる自由度

**物足りない所**
1. 初見の導きがない(最初の目標提示、操作チュートリアル)。「攻略目標」釦はあるが、最初の一歩の誘導ではない
2. 絵の訴求力。駒と旗の記号的表現は好みが分かれ、ストアページの一枚絵で損をする型。拡大時の地形のぼやけも気になる
3. 武将個人の物語(イベント)はまだ薄く、長期戦の単調さが出る可能性(今回の2時間では判定しきれず)
4. 引き継ぎ資料にある「50年回しても天下統一が起きない」バランス問題が残っているなら、一局を遊び切る動機に関わる(今回は未検証)

### 2. 売り先候補ごとの向き不向き

**Steam(本命)**
- 参入費: アプリ1本$100(売上$1,000到達で返金)。収益分配は開発者70%【出典: summerengine.com等のブログ解説。Valve公式partner.steamgames.comでの最終確認を推奨/低〜中】
- 厳しい統計: 2025年のインディー作品の総売上中央値は約$249、約40%は登録料$100を回収できず、$10万超は約8%(Gamalytic推計の二次報道 opencritic.com/news/22399等【中・推計】)
- 日本語ユーザーはSteam全体の約1.7〜2.6%(Valve調査の二次情報【中】)。日本語のみでは上限が低く、**戦国題材は簡体字中国語対応で市場が数倍に広がる可能性**(推測。三国志SLG文化圏との親和性による)
- 技術面: 一枚HTMLはElectron/Tauriでのラップで出品可能
- 向き: ◎。買い切りSLGの先行事例が最も豊富

**スマートフォン(App Store/Google Play)**
- 手数料は小規模開発者なら実質15%(両ストアの小規模プログラム【中・公式規約で要確認】)
- ただし日本のスマホゲーム市場(IAP 110億ドル超/年、Sensor Tower sensortower.com/blog/state-of-japan-gaming-2025【中〜高】)はガチャ運営型中心で、買い切りの市場は数%以下とみられる(推測)
- 審査リスク: WebView単純ラップはApple審査4.2「最小限の機能」・Google同趣旨ポリシーで却下され得る(Google公式ブログ android-developers.googleblog.com【高】ほか)。本作はオフライン完結なので通る余地はあるが、ネイティブ機能追加が安全策
- 向き: △。優先度低。スマホには「ブラウザでそのまま遊べる」ことを売りにする方が合う

**ブラウザ無料公開(広告・寄付)**
- itch.io: 収益分配は既定10%、投げ銭(Pay what you want)可【gamedeveloper.com・itch.io公式フォーラム/中〜高】。ブラウザゲームをそのまま掲載できる
- 国内: unityroom約180万訪問/月、PLiCy約48万、ふりーむ約47万(Semrush推計【低】)。開発者への広告収益分配は基本的にない(推測・要規約確認)
- 広告収益: Webゲームのリワード動画eCPMは$4〜15(広告ベンダー記事【低・宣伝バイアスあり】)。**月1万プレイでも月1万円前後の試算**(推測)
- 寄付: Patreonで最低賃金相当以上を稼ぐのは全体の2%という分析(theoutline.com、2017年データ【中・古い】)。FANBOX/Ko-fiの平均収益の信頼できる統計は見つからず(不明)
- 向き: ○。ただし**直接収益ではなく、Steam版への導線・ファン獲得装置として**

**DLsite・BOOTH**
- DLsite: 配信手数料は標準50%と報じられる(internet.watch.impress.co.jp/docs/yajiuma/1341811.html【中・現行料率は公式サークル規約で要確認】)。同人SLGの固定客層はあるが全年齢歴史SLGは主流ではない
- BOOTH: 5.6%+45円/件(2025年10月改定の解説記事【中】)。手数料最安だが集客力は弱く「既にファンがいる人向け」
- 向き: ○(併売)。追加コストほぼゼロなので並べる価値はある

### 3. 市場の大きさ

- 日本のゲームコンテンツ市場: 2024年2兆3,961億円、2025年2兆5,885億円(ファミ通ゲーム白書の発表報道 gamebiz.jp/news/410304, /430671【高】)。世界は約31〜32兆円
- 日本のPCゲーム市場: 約2,400億円(2024年、Newzoo/UKIE調べの二次報道【中】)。国内市場の約1割で成長してきたが今後は鈍化見込み
- 世界のストラテジーゲーム市場: 推計190〜230億ドル(2024-25年、商用調査各社【低〜中】)。ただし大半はF2Pモバイル運営型で、**個人開発買い切りSLGの到達可能市場とは別物**(推測)
- HTML5/Webゲームは2025年上半期に新作1.5万本超(前年同期比2.7倍)と**リリース数ベースでは再成長局面**(Playgama調査の報道 pocketgamer.biz【中】)。ただし中心は海外ポータルの広告型カジュアルで、日本語歴史SLGがこの波に直接乗れるかは不明

### 売れる見込みの幅(すべて推測。根拠は上記の類似事例と統計)

ブラウザ無料公開+寄付のみの場合は**月数千円〜数万円規模**に留まる可能性が高い(推測。広告eCPMとPatreon統計より)。

### 強み(市場文脈で)

1. **空白の価格帯**: 戦国SLGは「信長の野望(約1万円)」と「F2P運営型」に二極化しており、1,000〜2,000円で本格的な一国経営+合戦が遊べる買い切りはほぼ空白。Demigoddess!の成功はこの帯に需要がある証拠
2. **題材の普遍的人気**: SHOGUN 2が発売15年後も92%好評・6.6万件という事実は、戦国題材の世界的な底堅さを示す
3. **「ブラウザですぐ遊べる」こと自体が宣伝装置**: インストール不要の体験版は配信者・SNSでの拡散と相性が良い(Demigoddess!の勝因も配信者向けデモ)
4. 史実密度(武将972人・城271・偏諱・身分制)は、このジャンルの中核客層(歴史好き)への刺さりが深い

### 弱み

1. **発見されない危険が最大**: パブリッシャーなし・知名度ゼロの個人開発は、Steamの年間約1.9万本の新作に埋没する(500本以上売れたゲームの78%はパブリッシャー付きという講演データ【中】)
2. 絵の訴求力: ストア画面の見栄えで「地味」と判断されやすい。記号的な駒はゲーム内では機能的だが、宣材では弱い
3. 技術課題: 関ヶ原の動作の重さ、スマホ縦画面の窮屈さ(本報告一の4)
4. 一人開発の供給力: 運営型(アップデート継続)を期待される価格帯ではないが、発売後の不具合対応は必要
5. ゲームとしての決着(天下統一)が起きにくいバランス問題が未解決なら、レビューで突かれる(引き継ぎ資料より。今回未検証)

### 売り方の提案(推測を含む)

1. **二段構え**: ブラウザ版(序盤数年だけ遊べる無料体験版)をitch.io+自サイトで公開し、完全版をSteamで1,200〜1,980円。BOOTHでも併売(手数料5.6%+45円)
2. **Steam Nextフェスに合わせてデモを出す**。配信者がそのまま遊べる「関ヶ原モード」は配信向きの切り出しとして最適(10〜20分で山場が来るよう倍速調整を)
3. **出す前に直すべき三点**: (1)初プレイ誘導(最初の一手を指示する「軍師の助言」程度でよい)、(2)関ヶ原の速度(委任時の非描画計算)、(3)「GDD 7.3」等の内部表記の除去
4. **多言語は簡体字中国語を最優先**(推測): 戦国・三国志SLG文化圏で、Steamユーザーの26%超。英語は第二候補
5. スマホは「アプリ化」ではなく「スマホブラウザで遊べる」を宣伝文句にし、縦画面UIの改善に留める
6. 価格の目安は1,200〜1,980円(推測): Demigoddess!型の低価格帯より上、Shogun Showdown($14.99)と同水準。内容量はこの帯で十分戦える

### 分からなかったこと(正直に)

- 音の鳴り方(検証環境の制約で未確認。HTTP配信での確認が必要)
- 長期プレイ(数十年規模)の安定性・天下統一バランス(時間の制約で未検証)
- 海戦(コード・説明書には存在するが、今回のプレイでは発生させられなかった)
- DLsiteの現行手数料率、国内ブラウザ投稿サイトの収益条件、買い切りスマホ市場の正確な規模(いずれも一次資料にたどり着けず)
